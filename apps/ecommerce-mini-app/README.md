# Корзина Рядом

React-кейс магазина с самовывозом. Все товары, адреса и заказы вымышлены. Фотографии и схема пунктов хранятся в локальных WebP-файлах.

## Сценарии

- `#/catalog`: поиск по названию и производителю, категории, сортировка, диапазон цен и наличие. Карточка товара доступна по `#/product/rice`.
- `#/cart`: количество, сумма и выбранный пункт. Изменения нескольких вкладок объединяются.
- `#/checkout`: выбор пункта в отдельном окне, дата, получатель и состав заказа. Оформление фиксирует заказ и списание остатков одной записью.
- `#/orders`: история, отмена до готовности с возвратом остатков и повтор по текущему наличию. Замена непустой корзины требует подтверждения.

Принятый заказ открывается по `#/order/:id` с номером, статусом, пунктом, датой, составом и суммой. Сохраняются корзина, фильтры, остатки, данные получения и история. Ошибка запроса оставляет прежнее состояние; доступен явный повтор. Устаревшее подтверждение корзины требует повторной проверки.

Минимальный заказ составляет 100 ₽. Самовывоз бесплатный, оплата при получении. Пункты показаны на вымышленной схеме. При работе приложение обращается только к локальным файлам и хранилищу demo-kit.

## Запуск и проверки

Из корня репозитория:

```sh
npm run typecheck -w apps/ecommerce-mini-app
npx prettier --check apps/ecommerce-mini-app
node scripts/build.mjs ecommerce-mini-app
npm run scan
npm run serve
```

Локальный адрес: `http://localhost:4400/ecommerce-mini-app/`. Результаты команд и браузерных сценариев записаны в `VERIFICATION.md`. Визуальная система описана в `DESIGN.md`.
